网页本身不会写字，必须接大模型。本站接的是 **豆包（火山方舟）**。

## 三种用法

### 方式 A：本地（已就绪，直接能用）

双击 **`启动-豆包模式.bat`**：会读取本目录的 `.ark-key`（已有），启动服务并打开
<http://127.0.0.1:8099/judou/>。输入指令 → 选平台 → 生成。

- `.ark-key` 已在 `.gitignore`，不会进 Git
- 重新输入 Key：先复制新 Key，再双击 `配置-豆包Key（读剪贴板）.bat`
- 关服务：`Get-Process node | Where-Object { $_.Path -like '*OfficePLUSAgent*' } | Stop-Process`

### 方式 B：线上 + 浏览器直连

打开 <https://123212jjj.github.io/wuyu/judou/> → 创作台「接口」→ 粘贴 Key → 保存并测试。
Key 只存本机浏览器。若报「网络或跨域失败」，说明当前网络到方舟不通，用方式 A 或 C。

### 方式 C：线上 + Cloudflare Worker（最稳）

见 `cloudflare/README.md`：把 `worker.js` 贴进 Cloudflare Worker，加 `ARK_API_KEY` 环境变量，
再把 Worker 地址填到页面「代理地址」。

## 常见报错

| 报错 | 处理 |
|---|---|
| has not activated the model | 去方舟控制台「开通模型服务」 |
| The API key format is incorrect | Key 复制错/失效，重新创建 |
| 网络或跨域失败 | 用方式 A（本地）或方式 C（Worker） |
| 模型不存在 | 把控制台里的 `ep-xxxx` 填到「模型接入点」 |
