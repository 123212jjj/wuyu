# 豆包文字生成 · 接入说明

网页本身不会写字，必须接一个大模型。当前站接的是**豆包（火山方舟）**，Key 有两个来源：你自己申请的方舟 API Key。
方舟新用户有免费额度，够测试用。

---

## 一、先领 Key（约 3 分钟）

1. 打开 <https://console.volcengine.com/ark>
2. 用手机号/抖音扫码登录，按提示完成**实名认证**（个人即可）
3. 左侧 **模型广场** → 搜「豆包」→ 开通 **豆包 Seed 2.0 Pro**（或 Lite / Mini，开通即享新用户免费额度）
4. 左侧 **API Key 管理** → **创建 API Key** → 复制那串 `ark-...`（只显示一次，先存好）
5. 可选：如果提示需要「推理接入点」，去 **在线推理 → 创建推理接入点**，把 `ep-xxxxxxxx` 记下来

> 页面里所有地方都不需要你填「账号密码」，只要这个 Key。

---

## 二、三种用法，按你的情况选一种

### 方式 A：本地跑（最稳，推荐先跑通这个）

1. 双击仓库根目录（`C:\Users\caojingxuan\Desktop\前端网页`）的 **`启动-豆包模式.bat`**
2. 黑窗口里**粘贴 Key**（输入不显示），回车
3. 浏览器自动打开 <http://127.0.0.1:8099/judou/>
4. 输入创作指令 → 选平台 → 点「生成小红书文案」

- Key 只传给本地服务进程，不写文件、不进 Git
- 关掉服务：`Get-Process node | Where-Object { $_.Path -like '*OfficePLUSAgent*' } | Stop-Process`

### 方式 B：线上 + 浏览器直连（不用服务器）

1. 打开 <https://123212jjj.github.io/wuyu/judou/>
2. 创作台点 **「接口 · 未配置 Key」** → 粘贴 Key → **保存并测试**
3. 显示「连接成功」即可直接生成

- Key 存在你这台电脑的浏览器里（`localStorage`），不上传 GitHub
- 如果报「网络或跨域失败」，说明你当前网络到方舟不通，改用 **方式 C** 或 **方式 A**

### 方式 C：线上 + Cloudflare Worker 代理（最稳的线上方案）

把 Key 放到 Cloudflare，页面只连你的 Worker，不受本机网络影响。

1. 打开 <https://dash.cloudflare.com/> → **Workers & Pages** → **Create** → **Worker** → 起名 → Deploy
2. **Edit code** → 把 `cloudflare/worker.js` 全文粘进去 → Deploy
3. **Settings → Variables and Secrets** 添加：
   - `ARK_API_KEY`（类型 **Secret**）= 你的方舟 Key
   - 可选 `ARK_MODEL` = `ep-xxxxxxxx`
4. 复制 Worker 地址，例如 `https://judou-ark-proxy.xxx.workers.dev`
5. 回到创作台 → 「接口」→ **代理地址** 填这个 URL → 保存并测试

详见 `cloudflare/README.md`。

## 三、常见报错对照

| 报错 | 原因 | 处理 |
|---|---|---|
| 还没有配置豆包接口 | 没填 Key | 方式 A 启动，或页面里填 Key |
| The API key format is incorrect | Key 复制错了/失效 | 重新创建 API Key |
| 模型不存在 / 404 | 用了不存在的模型名 | 在「模型接入点」里填 `ep-xxxxxxxx` |
| 网络或跨域失败 | 本机网络到方舟不通 | 用方式 A 或方式 C |
| 401 / 403 | Key 无权限或未开通模型 | 控制台开通模型、检查额度 |

## 四、验证「真的在调模型」的小技巧

- 生成的内容**明显贴合你输入的具体主题**（比如你写「咖啡，简约，大英字母，下午」，出来就是咖啡），说明是模型生成
- 结果页标题每次都不一样；打开浏览器 F12 → Network，能看到请求 `ark.cn-beijing.volces.com`（方式 B）或你的 Worker 地址（方式 C）
